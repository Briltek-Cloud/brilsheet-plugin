# BrilSheet

BrilSheet gives Claude Sheet skills, Apps Script skills and a connector between them, so Claude can read and update the Apps Script behind your Google Sheets from the Claude sidebar. Ask for a menu, a schedule, an email or a fix in plain words; Claude writes the code, keeps a backup before every change, and reports what changed and how it affects Google's limits.

## Use it

1. Install BrilSheet from Customize > Plugins, then click Connect on its Connectors tab and sign in with Google.
2. In Google Sheets, open Extensions > Claude > Open Claude, and make sure BrilSheet is on under + > Connectors.
3. Ask for what you want, for example "Email me every Monday at 8am with last week's sales". The first time, Claude shows you how to link the sheet's script.

## Data

BrilSheet reads and saves the Apps Script of sheets you can edit, and a hidden label that records which script belongs to each sheet, through your own Google sign-in. It stores nothing on its own servers. Backups are versions in your script's Project history.
